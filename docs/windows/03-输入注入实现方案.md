# Windows 输入注入模块实现方案

本文档详细描述 Windows 平台输入注入模块的技术选型、实现方案和注意事项。

## 一、技术概述

### 1.1 需要实现的功能

根据 [input/mod.rs](../../crates/server/src/input/mod.rs) 定义的 `InputInjector` trait：

| 方法 | 功能 | 输入来源 |
|------|------|---------|
| `move_mouse(x, y)` | 鼠标移动到绝对坐标 | 浏览器 `mousemove` 事件 |
| `mouse_button(btn, pressed)` | 鼠标按键按下/释放 | 浏览器 `mousedown/mouseup` |
| `scroll(dx, dy)` | 滚轮滚动 | 浏览器 `wheel` 事件（deltaX/deltaY） |
| `key(code, pressed)` | 键盘按键按下/释放 | 浏览器 `keydown/keyup` 的 `KeyboardEvent.code` |

### 1.2 技术方案对比

#### 方案 A：使用 enigo crate（当前 stub 实现）

| 维度 | 评估 |
|------|------|
| **实现复杂度** | **最低**，API 简洁 |
| **跨平台一致性** | 好，与 X11 实现共用相同 API |
| **滚轮支持** | 有，但可能存在兼容性问题 |
| **依赖** | enigo crate（已在用） |
| **缺点** | 无法使用 Windows 特有功能（如精确滚轮控制） |

**enigo 底层实现：**
- 鼠标：调用 Windows `SendInput` API
- 键盘：调用 Windows `SendInput` API
- 滚轮：通过 `Button::ScrollUp/ScrollDown`

#### 方案 B：直接使用 Windows SendInput API

| 维度 | 评估 |
|------|------|
| **实现复杂度** | 中等，需要处理结构体和标志位 |
| **控制精度** | **最高**，可精确控制每个参数 |
| **滚轮支持** | 完整支持纵向/横向滚轮、精确滚轮量 |
| **依赖** | windows crate（已添加） |
| **缺点** | 代码复杂度较高，需手动处理键盘映射 |

**SendInput API 特点：**
- 统一的输入注入接口（鼠标、键盘都使用）
- 支持精确滚轮控制（`MOUSEEVENTF_WHEEL` 带滚动量）
- 支持横向滚轮（`MOUSEEVENTF_HWHEEL`）
- 支持扩展键（如多媒体键）

---

## 二、推荐方案：混合实现

结合两种方案的优点：

| 功能 | 实现 | 原因 |
|------|------|------|
| **鼠标移动** | enigo | API 简洁，底层调用 SendInput |
| **鼠标点击** | enigo | API 简洁，无需手动处理标志位 |
| **滚轮** | SendInput | enigo 滚轮支持有限，SendInput 可精确控制滚动量 |
| **键盘** | enigo | keymap 映射逻辑已完善，enigo 封装简化调用 |

**优势：**
- 保持代码简洁（大部分功能用 enigo）
- 滚轮功能完整（直接调用 SendInput）
- 与 X11 实现风格一致（X11 也采用 enigo + XTest 滚轮混合）

## 三、鼠标移动实现

### 3.1 enigo 方案

```text
enigo.move_mouse(x, y, Coordinate::Abs)
```

底层调用：`SendInput` 配合 `MOUSEEVENTF_MOVE | MOUSEEVENTF_ABSOLUTE`

### 3.2 DPI 感知问题

| 问题 | 说明 |
|------|------|
| **坐标错位** | 高 DPI 显示器下，浏览器发送的逻辑坐标与 Windows 物理坐标不同 |
| **症状** | 鼠标点击位置与实际位置偏移（偏移量 = DPI 缩放比例） |

**解决方案：**

1. **应用启动时启用 DPI 感知**
   
   在程序入口调用：
   ```text
   SetProcessDPIAware() 或 SetProcessDpiAwarenessContext(DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE)
   ```

2. **或修改 main.rs 添加 DPI 感知声明**

   在编译时通过 Windows manifest 嵌入：
   ```xml
   <dpiAware>true/pm</dpiAware>
   ```

3. **验证方式**

   启动服务时日志输出 DPI 缩放比例，方便排查问题。

### 3.3 多显示器坐标

Windows 使用 Virtual Screen 坐标系：

```
Virtual Screen 坐标系（与 Desktop Duplication 对齐）:

         (-1920, 0)        (0, 0)           (1920, 0)
            ↓                 ↓                 ↓
    ┌─────────────┐   ┌─────────────┐   ┌─────────────┐
    │  Monitor 2  │   │  Monitor 1  │   │  Monitor 3  │
    │  (副显示器)  │   │  (主显示器)  │   │  (副显示器)  │
    │  1920x1080  │   │  1920x1080  │   │  1920x1080  │
    └─────────────┘   └─────────────┘   └─────────────┘
```

- 坐标来自浏览器，浏览器使用 Virtual Screen 坐标系
- 鼠标移动直接使用该坐标即可（无需转换）
- 与 Desktop Duplication 捕获的屏幕坐标一致

## 五、滚轮实现（关键点）

### 5.1 现有 stub 问题

当前 `windows.rs` 的滚轮实现：

```text
// 简单实现：每次只滚动一格
if dy > 0 {
    button(ScrollUp, Press)
    button(ScrollUp, Release)
}
```

**问题：**
- 每次只滚动一个固定量，无法反映浏览器 wheel delta 的实际滚动量
- 不支持横向滚轮（dx）
- 无法精确控制滚动距离

### 5.2 SendInput 精确滚轮方案

**API 调用：**

```text
SendInput(1, &INPUT {
    type: INPUT_MOUSE,
    mi: MOUSEINPUT {
        dwFlags: MOUSEEVENTF_WHEEL,
        mouseData: scroll_amount,  // 滚动量（正数向上，负数向下）
        ...
    }
})
```

**关键参数：**

| 参数 | 说明 |
|------|------|
| `dwFlags` | `MOUSEEVENTF_WHEEL`（纵向）或 `MOUSEEVENTF_HWHEEL`（横向） |
| `mouseData` | 滚动量，单位是 `WHEEL_DELTA`（默认 120） |
| `dx/dy` | 0（滚轮不移动鼠标位置） |

**滚动量计算：**

```text
浏览器 wheel deltaY 单位：像素
Windows WHEEL_DELTA 单位：120 = 滚动一格

转换公式：
wheel_delta = deltaY / 120 * scale_factor

简化实现：
wheel_delta = deltaY.clamp(-10, 10)  // 限制范围，避免极端值
```

### 5.3 实现逻辑

```text
fn scroll(&mut self, dx: i32, dy: i32) -> Result<()> {
    // 纵向滚轮
    if dy != 0 {
        let amount = calculate_wheel_delta(dy);
        send_mouse_wheel(WHEEL, amount);
    }
    
    // 横向滚轮
    if dx != 0 {
        let amount = calculate_wheel_delta(dx);
        send_mouse_wheel(HWHEEL, amount);
    }
}

fn calculate_wheel_delta(delta: i32) -> i32 {
    // 将浏览器像素 delta 转换为 Windows wheel delta
    // WHEEL_DELTA = 120，浏览器通常 deltaY = 100~150 一格
    // 简化：每 120 像素 = 一个 wheel delta
    let scaled = delta / 120;
    if scaled == 0 && delta != 0 {
        // 小量滚动至少触发一个 delta
        if delta > 0 { 120 } else { -120 }
    } else {
        scaled.clamp(-1200, 1200)  // 最多 10 格
    }
}
```

### 5.4 与 X11 实现对比

| 平台 | 滚轮实现方式 | 滚动量控制 |
|------|-------------|-----------|
| X11 | x11rb XTest（button 4/5/6/7） | 离散点击次数，每点击一格 |
| Windows | SendInput MOUSEEVENTF_WHEEL | 精确滚动量，可连续滚动 |

**Windows 优势：** 可精确控制滚动距离，更接近浏览器原生滚动体验。

## 六、键盘实现

### 6.1 键盘映射流程

```
浏览器 KeyboardEvent.code
         ↓
   keymap::code_to_key()
         ↓
    enigo::Key 枚举
         ↓
   enigo.key(key, direction)
         ↓
   Windows SendInput (INPUT_KEYBOARD)
```

### 6.2 keymap.rs 映射表

当前 [keymap.rs](../../crates/server/src/input/keymap.rs) 已完整支持：

| 键类型 | 示例 | enigo Key |
|--------|------|-----------|
| 字母 | `KeyA` | `Key::Unicode('a')` |
| 数字 | `Digit1` | `Key::Unicode('1')` |
| 功能键 | `F1` | `Key::F1` |
| 方向键 | `ArrowUp` | `Key::UpArrow` |
| 修饰键 | `ShiftLeft` | `Key::LShift` |
| 小键盘 | `Numpad1` | `Key::Numpad1` |
| 符号 | `Minus` | `Key::Unicode('-')` |

**Windows 特殊处理：**
- `ScrollLock` 在 Windows 使用 `Key::Scroll`（已条件编译处理）
- `PrintScreen`、`Pause` 等已映射

### 6.3 enigo 键盘实现

```text
fn key(&mut self, code: &str, pressed: bool) -> Result<()> {
    let Some(key) = keymap::code_to_key(code) else {
        warn!("未支持的键码 '{}'", code);
        return Ok(());  // 忽略未知键
    };
    
    let direction = if pressed { Direction::Press } else { Direction::Release };
    self.enigo.key(key, direction)?;
    Ok(())
}
```

### 6.4 Windows Virtual Key Codes

**enigo 底层映射：**

| enigo Key | Windows VK Code |
|-----------|-----------------|
| `Key::A` (Unicode) | `VkKeyScan('a')` → VK |
| `Key::F1` | `VK_F1` (0x70) |
| `Key::LShift` | `VK_LSHIFT` (0xA0) |
| `Key::Return` | `VK_RETURN` (0x0D) |

enigo 内部通过 `MapVirtualKey` 和 `VkKeyScan` 完成映射。

## 七、DPI 感知详细方案

### 7.1 问题背景

| 场景 | 问题 |
|------|------|
| 125% DPI缩放 | 浏览器发送坐标 (100, 100) → Windows 物理坐标 (125, 125) |
| 无 DPI 感知 | 程序使用逻辑坐标 → 鼠标实际点击位置偏移 25% |

### 7.2 解决方案

**方案 A：运行时调用 API**

```text
SetProcessDpiAwarenessContext(DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE_V2)
```

需要在 main.rs 的 `main()` 函数最开始调用。

**方案 B：编译时嵌入 Manifest**

创建 `app.manifest` 文件：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<assembly xmlns="urn:schemas-microsoft-com:asm.v1" manifestVersion="1.0">
  <assemblyIdentity version="1.0.0.0" name="RemoteControl"/>
  <application>
    <windowsSettings>
      <dpiAware xmlns="http://schemas.microsoft.com/SMI/2005/WindowsSettings">true/pm</dpiAware>
      <dpiAwareness xmlns="http://schemas.microsoft.com/SMI/2016/WindowsSettings">PerMonitorV2</dpiAwareness>
    </windowsSettings>
  </application>
</assembly>
```

Cargo.toml 配置嵌入：
```toml
[target.'cfg(windows)'.build-dependencies]
embed-manifest = "1.4"
```

### 7.3 推荐方案

**方案 A（运行时调用）更简单：**

- 无需额外文件和构建依赖
- 在 main.rs 添加几行代码即可
- windows crate 已提供 API

## 八、错误处理

### 8.1 可能的错误

| 错误场景 | 原因 | 处理方式 |
|---------|------|---------|
| enigo 初始化失败 | 系统限制（如 UAC 阻止） | 返回 Error，服务无法启动 |
| SendInput 失败 | 权限不足、会话限制 | 返回 Error，记录日志 |
| 键盘映射失败 | 未知键码 | 记录 warn 日志，返回 Ok（忽略该键） |

### 8.2 UAC 与权限

| 情况 | 说明 |
|------|------|
| 普通用户运行 | **正常可用**，SendInput 不需要管理员权限 |
| UAC 提权对话框 | 如果目标窗口是管理员权限程序，注入可能无效 |
| 服务模式运行 | 输入注入需要会话 0 隔离处理（本项目不涉及） |

## 十、SendInput API 详细用法

### 10.1 结构体定义

```rust
// windows crate 提供的结构体

use windows::Win32::UI::Input::KeyboardAndMouse::*;

// INPUT 结构体
struct INPUT {
    type: INPUT_TYPE,  // INPUT_MOUSE 或 INPUT_KEYBOARD
    Anonymous: INPUT_0,  // 包含 mi 或 ki
}

// MOUSEINPUT 结构体
struct MOUSEINPUT {
    dx: i32,
    dy: i32,
    mouseData: u32,     // 滚轮量
    dwFlags: MOUSE_EVENT_FLAGS,
    time: u32,
    dwExtraInfo: usize,
}

// 滚轮相关标志
MOUSEEVENTF_WHEEL    = 0x0800  // 纵向滚轮
MOUSEEVENTF_HWHEEL   = 0x0800? // 横向滚轮（不同值）
```

### 10.2 SendInput 调用

```rust
fn send_wheel(amount: i32, is_horizontal: bool) -> Result<()> {
    let flags = if is_horizontal {
        MOUSEEVENTF_HWHEEL
    } else {
        MOUSEEVENTF_WHEEL
    };
    
    let input = INPUT {
        type: INPUT_MOUSE,
        Anonymous: INPUT_0 {
            mi: MOUSEINPUT {
                dx: 0,
                dy: 0,
                mouseData: amount as u32,
                dwFlags: flags,
                time: 0,
                dwExtraInfo: 0,
            }
        }
    };
    
    SendInput(1, &[input], std::mem::size_of::<INPUT>())?;
    Ok(())
}
```
