# RemoteControl 设计文档

一个用 Rust 开发的远程桌面控制系统。用户通过浏览器访问，浏览器把鼠标、键盘操作发送给被控端电脑上运行的服务，服务在本机模拟鼠标键盘操作，同时把屏幕画面实时编码回传给浏览器显示。

## 需求基线

| 维度 | 决策 |
| --- | --- |
| 被控端平台 | Linux(X11)、Windows 优先实现；Linux(Wayland) 预留接口，暂不实现 |
| 画面回传 | 需要实时视频流 |
| 网络拓扑 | 同一局域网 / 可直连，无需中转服务器（架构预留可扩展） |
| 安全 | 简单密码认证 + 传输加密(TLS/wss) |
| 开发语言 | Rust（被控端服务）+ 浏览器原生 Web（前端） |

## 一句话架构

```
┌─────────────┐   wss (WebSocket over TLS)   ┌──────────────────────────┐
│   浏览器     │ ───── 输入事件(鼠标/键盘) ──> │      Rust 被控端服务       │
│  (Web 前端)  │                              │                          │
│             │ <──── 视频流(H.264 分片) ───── │  捕获 → 编码 → 输入注入    │
└─────────────┘                              └──────────────────────────┘
```

被控端是单个 Rust 二进制，内置 HTTP/WebSocket 服务器，既托管前端静态资源，又处理实时双向通信。
